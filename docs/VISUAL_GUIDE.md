# 0.6 视觉与素材核对

本页供源码维护者、测试者与投屏演示操作者使用。目标版本为 `0.6.0-phase1`：二十处场所、十人统一头像／详情、默认 123 张本次贴纸及 20 张旧版补充，默认浅色并可切深色。以下是应核对的结果，不表示真实浏览器、手机或公网已经通过；实际记录放在 [acceptance.json](acceptance.json)。

Sites 固定页已按本轮目标接入 Workers／D1 共享服务；保留的 FastAPI／SQLite 路径使用同一套前端。每份结果注明实际版本、入口和设备。HTTP／DOM 自动化不代替浏览器排版、软键盘或大陆真人网络；显式离线评审也不作为后端权限证据。项目、实际发布与数据范围见 [SITES_ITERATION](SITES_ITERATION.md)。

本轮品牌标识统一使用 `/static/onstage-mark.svg` 的粉色／青色双星：favicon、页头、加载与页脚应一致。原图人物、场景和贴纸文件不因这个标识变更而重绘。

**按当前版本重新核对新入口与人物图。** 0.4 保存版本 2 的平台首页截图保留为历史，不能代签本次替换后的头像、昵称入口或手机布局。当前版本的图源核对、自动化及平台图像证据分别记入 acceptance.json。

用户暂不提供当前 ChatGPT 设备控制。真实桌面交互、360／390 像素布局、手机触摸与软键盘交由本地 Codex 按 [CODEX_HANDOFF](CODEX_HANDOFF.md) 验收；没有实际执行就标未验证。原托管预览受环境限制，DOM/API 自动化不是浏览器排版结果。

## 画面与交互

| 项目 | 核对方法与通过条件 |
| --- | --- |
| 房间全幅场景 | 分别打开明亮室外和深色室内场所。图片成为整个房间区域的环境背景；桌面和手机都能辨认场所特征，不能只剩标题横幅。文字、角色和操作层仍清晰，背景不截获点击。 |
| 可读与滚动 | 用长房主背景、长公告及连续消息检查换行和滚动。窄屏无整页横向溢出，最后一条消息与发送控件可达，打开软键盘后能看见输入和提交结果。 |
| 十人同套人物原图 | 逐一打开十个角色详情，对照小头像核对发色、发型、眼睛、服装、姓名与乐队。使用同套官方原图，头像通过统一的裁切方法聚焦脸部，详情保留原始画面比例；不能混用 AI 重绘或另一套衣服。 |
| 昵称与旁观入口 | 首次进入填昵称，无密码、验证码或注册；邀请地址不会在填完昵称后丢失。房间明确显示旁观状态，房主能找到成员管理与移出确认，普通成员没有管理权限。 |
| 手机分栏与弹层 | 在大厅、房间、角色／场控等实际可用分栏之间切换，打开并关闭角色详情和贴纸面板。返回原位置后没有丢失草稿、误切频道或被旧弹层遮挡；触控关闭与键盘焦点以真实设备结果为准。 |
| 主题偏好 | 新浏览器会话默认浅色；手动切换深色后刷新仍保留偏好。两主题都核对输入、错误提示、角色名、贴纸和按钮，不以场景图片本身偏暗代替深色主题。 |
| 减少动态效果 | 开启系统“减少动态效果”后核对头像、装饰与过渡，本版应停用相关动效。普通模式中仅新到达的消息／贴纸播放一次入场效果，历史回看不反复播放，也不能移动点击目标或干扰阅读。 |

房间场所是环境，不是规定剧情的任务页。全幅背景不能增加强制冲突、倒计时或结局；房主故事背景与公告仍是独立文本，舞台／后台权限保持不变。

## 默认 123 张与历史兼容

面板默认选择“本次 123”（`user-v04`），按用户原来的 11 个分类和标签搜索。切换“全部 143”后可继续使用其中保留的旧版补充二十张（`starter-v03`），不需要寻找独立的旧版补充按钮；与旧包相同的二十张不重复放入两份资源。“真奈”五张可作为贴纸使用，角色选择仍只有既有十人。具体分类计数见 [CONTENT_SOURCES](CONTENT_SOURCES.md)。

点选贴纸先预览，再通过独立发送操作提交。文字草稿与每房、每频道的贴纸选择分别暂存，切换后应能恢复；变更来源、分类或搜索条件不能把点选预览误作已发送消息。检查原中文分类、同名标签和空搜索结果是否可理解，旧版补充可被明确找到。

贴纸原文件已通过解码、帧数与尺寸核对，均为未经改动的 162×162 静态 PNG。浏览器仍需检查图片可见、标签和可选状态，以及面板在手机上的滚动、预览、发送、取消和关闭。122 张有透明像素；`真奈/五冠王3.png` 原本不透明，保留橙色卡面，不能为统一外观改图。文件审计与浏览器实际排版分别记录。

完整服务的三端回归至少覆盖：

1. 两名演员分别发送文字与贴纸，第三位旁观者同时观看；内容和实际作者一致。允许演员使用整包，素材人物不改变占角。
2. 断开一个客户端，期间另一个客户端发送一条文字及一张贴纸；恢复后完整补齐，不重复。发送失败时重试的是原消息，不自动换贴纸或换频道。
3. 刷新、返回大厅重入及结束后回看，贴纸继续出现。结束后文字与贴纸均不能新发；旁观者不能向舞台／后台发贴纸或读取后台记录。
4. 对事先约定的演示贴纸提交测试举报，核对真实作者、素材快照和回执。提交成功不表示违规成立；不能借贴纸举报读取无权限的后台。

正常已发贴纸下面不显示名称，去掉额外矩形底框；搜索标签与图像 alt 保留。贴纸资源失效时仍需显示发送时可辨认的文字回退（如 `[贴纸] 标签`），不形成空白消息；不可加载客户端任意提供的替代 URL。历史按保存的快照解释，换目录不改旧消息或举报。已经入库的消息即使贴纸后来下架，也应在当前身份与读取权限有效时恢复原确认；下架贴纸不得作为新消息发送。

本轮对原包全部 123 张核对了尺寸与透明度，并查看了灯／初华的两张“害羞”和旧版灯“害羞”原文件。页面此前额外添加浅色背景、边框与阴影，本轮只移除这层样式；不擅自擦除原作白色描边或把 162 像素图片重绘成所谓高清版。详见 [sticker-display-audit-v05.json](../reports/sticker-display-audit-v05.json)。
